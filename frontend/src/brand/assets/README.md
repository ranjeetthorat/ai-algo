# FastAlgo brand assets

Source of truth for the FastAlgo logo files. The spec is in
`docs/design/brand/design-language.md` (section 5). Every file here is
generated by `scripts/brand/build_brand_assets.py`, so regenerate rather than
editing by hand.

| File | Use |
| --- | --- |
| `fastalgo-mark.svg` | The mark: Ink tile with two teal chevrons. Vector master |
| `fastalgo-glyph.svg` | Chevrons only, transparent, cropped. Chart watermarks and small inline use |
| `fastalgo-wordmark-light.svg` | Mark plus "fastalgo" for light backgrounds |
| `fastalgo-wordmark-dark.svg` | Mark plus "fastalgo" for dark backgrounds |
| `logo.png` | 512 px mark. Replaces `frontend/public/logo.png` in M1.3 |
| `android-chrome-192x192.png` | 192 px mark. Replaces `frontend/public/images/android-chrome-192x192.png` in M1.3 |
| `apple-touch-icon.png` | 180 px full-bleed square (iOS rounds the corners). Replaces `frontend/public/apple-touch-icon.png` in M1.3 |
| `favicon.ico` | 16, 32 and 48 px. Replaces `frontend/public/favicon.ico` in M1.3 |

The wordmark text is Manrope (SIL Open Font License 1.1), converted to outlines.
No font file ships with the app.
